# 四国サーフナビ MVP

「今日はどこのポイントへ行けば良いか」を素早く判断する、四国限定のサーフポイント推薦 PWA。
気象データの羅列ではなく、**各ポイントの「おすすめ度」をスコアとコメントで提示**するのがコンセプトです。

- 対応地域: 四国のみ
- 対応ユーザー: 四国在住サーファー / 週末サーファー / 初心者〜中級者
- 技術: React + TypeScript + Tailwind CSS v4 + Vite + PWA(手書き Service Worker)
- バックエンド不要 / データはブラウザの localStorage に保存
- 予報 API: [Open-Meteo](https://open-meteo.com/)(気象 API + Marine API・要帰属表示 CC BY 4.0)

## 画面構成

| 画面 | 内容 |
|------|------|
| ホーム | 今日のおすすめランキング(1〜3位をカード、4位以降はリスト)。各カードに総合評価・星評価・風/波のサマリーチップ・一言コメント |
| ポイント詳細 | 総合評価(スコアリング+星)、現在予報(風向・風速・波高・うねり方向・気温)、本日の推移チャート(6〜19時の波高/風速+ベストタイム)、評価理由のコメント |
| ポイント管理 | ポイントの追加・編集・削除。名称/緯度/経度 + サーフ条件マスタ(向き・なじみサイズ・レベル帯・底質) |

## スコアリング仕様(独自ロジック)

0〜100 点 = **風 40 点** + **うねり 45 点**(入射角 50%・なじみサイズ 35%・周期 15%)で計算。

- 風: ポイントの向きから求めたオフショア方位との角度差で判定。風速 3m/s 未満は「無風」として高評価、オンショア+強風は最低評価
- うねり: ポイント向きと入射角の一致度 × なじみサイズへの収まり(小さすぎ/大きすぎを減点) × 周期(10 秒以上を高評価)
- ガード: 波高 0.25m 未満はフラット扱いで上限 42 点、なじみサイズの 2 倍超は上限 48 点
- 星: 85+ = 5 / 70+ = 4 / 53+ = 3 / 36+ = 2 / 未満 = 1

評価理由(例: 「北東風のオフショア。面が整いやすい」「南東うねりがまっすぐ入る向き」)は上記判定と同時に生成されます。
"ベストタイム"は本日 6〜19 時で各時刻に同じ計算を適用し、最大スコアの時刻を表示します。

## ポイント条件マスタ(全項目ブラウザ保存・編集可)

| 項目 | 説明 |
|------|------|
| 向き(bearing) | ポイントが海に向いている方位。うねりの入射角とオフショア風向の計算に使用 |
| なじみサイズ | 良い波になる波高レンジ(m)。ポイントごとの規模感を反映 |
| レベル帯 | 初心者OK / 中級以上。大きなサイズ時の減点に影響 |
| 底質 | サンド / ミックス / リーフ(表示用) |

## 開発

```bash
npm install
npm run dev        # ローカル開発
npm run build      # 型チェック + 本番ビルド(dist/)
npm run build:demo # 1ファイルに全JS/CSSをインライン化したデモ(dist-demo/)
```

## PWA としてデプロイ

`npm run build` の `dist/` を Netlify / Vercel / Cloudflare Pages 等の**HTTPS のルート**に置くだけでインストール可能な PWA になります。

- `public/manifest.webmanifest` … アイコン・テーマカラー等
- `public/sw.js` … アプリシェルのキャッシュ(オフライン起動可)。予報 API はキャッシュせず、最新の予報は localStorage に保存してオフライン時はそれを表示
- サブパス(例: GitHub Pages の `repo/`)に置く場合は `vite.config.ts` に `base` を追加し、manifest の `start_url`/`scope` を調整してください

アイコンの再生成: `python3 scripts/make_icons.py`(Pillow が必要)

## データ・免責
